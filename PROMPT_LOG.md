## Задание 3: Рефакторинг «плохого» кода
### Промпт 1
**Инструмент:** koda-pro
**Промпт:** "Cгенерируй «плохую» функцию на Python для расчёта итоговой стоимости проживания в гостинице (цена за ночь * количество ночей + сезонный коэффициент + доплата за гостя). Функция должна быть длиной >30 строк, содержать магические числа, дублирование, неинформативные имена переменных и отсутствие обработки ошибок."
**Результат:** Написан файл bad_calculator.py, где в функции f:
   - Неинформативные имена: f, p, n, g, s, e, c, r, x, y, z
   - Магические числа: 1.5, 500, 0.95, 100, 0.1, 200 и десятки других без пояснений
   - Дублирование: проверки g > 2/4/6, e == 1/2, s == 1/2 повторяются 3-4 раза
   - Dead code: elif n > 14: и elif n > 30: никогда не выполнятся, т.к. n > 7 перехватывает их раньше
   - Нет валидации: отрицательная цена, нулевые ночи, None — всё ломается
   - Side effect: print(z) внутри функции
### Промпт 2
**Инструмент:** koda-pro
**Промпт:** "Выполни рефакторинг этой функции с объяснением каждого изменения."
**Результат:** Написан файл calculator.py — рефакторинг:
    - Неинформативные имена → `calculate_total_cost(price_per_night, nights, guests, season, extra_service)`
    - Магические числа→ `Season` и `ExtraService` enum, именованные константы
    - Дублирование → вспомогательные функции (`_guest_tiered_surcharge`, `_duration_discount` и др.)
    - Мёртвый код → исправлен порядок условий (>30 → >14 → >7)
    - Нет валидации → `raise ValueError` на неположительных параметрах
    - print() внутри функции → удалён, возвращается `round(total, 2)`
    - Type hints → все параметры и возвращаемые значения типизированы
